## Weekly Summary

### Week 1 - HTML Fundamentals
Installed and configured primary and secondary code editors (Visual Studio Code and Sublime Text) 
with essential web development extensions, then verified the environment setup by creating and 
displaying a basic test HTML page.

### Week 2 - Semantic & Multimedia
Designed a structured HTML5 web page using semantic elements like <header>, <nav>, <main>, and 
<footer>, while embedding multimedia content and section navigation links.

### Week 3 - CSS Basics
Styled an HTML web page by linking an external CSS stylesheet, utilizing the CSS box model for 
spacing, adding hover effects to interactive elements, and setting up responsive media queries 
for smaller screens.

### Week 4 - JavaScript Basics and DOM Manipulation
Built interactive web features using external JavaScript and DOM manipulation, including a live 
updating header clock, a persistent light/dark mode using local storage, a dynamic to-do list, 
and a modal popup with email form validation.

### Week 5 - Javascript Functions and Bootstrap
Refactored and modernized the web page using the Bootstrap framework, integrating a responsive 
navigation bar, an image carousel slider, grid layouts with service cards, and a multi-column 
footer.

### Week 6 - API & Client Storage
Integrated client-side storage and external REST APIs using JavaScript, allowing users to save 
personal preferences in local storage, query weather updates via OpenWeatherMap API, display 
dynamic maps using Google Maps API, and look up public profile data using GitHub API.

### Week 7 - MiniFullStackStarter
Developed and deployed a full-stack mini web application using Node.js, Express, Mongoose, and 
MongoDB Atlas, setting up backend CRUD routes with a Bootstrap frontend, and hosting the live 
service online via Render.
